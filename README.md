# Problem Finding

A single-page site summarizing four readings on problem finding (Assignment 01). Built with React, Vite, TypeScript and Tailwind CSS v4.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check and build to dist/
npm run preview  # serve the production build
```

## Edit it

- Your name, date and class: `student` in `src/data.ts`.
- All text, statistics and references: `src/data.ts`.
- Colors and fonts: the `@theme` block in `src/index.css`.

Check every quote, statistic and page number against your course copies before submitting.
